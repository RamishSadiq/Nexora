# Nexora beginner documentation

Start with **Nexora complete beginner guide.html**. This single offline file contains all 30 teaching guides, embedded diagrams, searchable file maps and the full captured source library. It works in a browser without a server or network connection. Select a guide, read its explanation, then use its frontend/backend/data buttons to open the corresponding source.

The **Nexora complete beginner guide.docx** is the combined editable Word teaching manual. It contains the same explanations and short, explicitly labelled code extracts. The HTML library holds all complete supporting files once, avoiding a printed appendix of more than 150,000 lines. Each individual Markdown guide also includes its three complete primary implementation files. The original approved login Word guide is retained with its original code appendix.

## Coverage and evidence

The source snapshot was captured on 13 October 2026 at 17:12:59 UTC and reflects the working checkout, including uncommitted application changes. It covers the three Nexora application surfaces, nine backend modules, nine concrete database contexts, all 47 page/layout/HTTP route entries, and 686 captured text files containing 151,827 source lines. Binary media, framework internals, generated build outputs and local environment files are outside the source library. Selected debug configuration is included with its configured local password explicitly omitted. The manifest stores original file fingerprints and marks redacted files.

The guide builders verify every primary path and exercise search phrase and map all captured files to chapters. Browser checks validate the offline manual, source selection, search, filters, raw source download, mobile layout and absence of external requests. Word output is exported with Microsoft Word and rendered for page-by-page visual review. QA PDFs, screenshots and intermediate evidence remain in ignored artifacts.

These are documentation checks. They do not claim that every application regression or authenticated business journey ran again, or that unfinished providers are production-ready. The manuals name current limitations in each chapter.

## Maintenance

Editorial content: scripts/docs/platform_guide_catalog.py. Builder: scripts/docs/Build-PlatformGuides.py. Word renderer: scripts/docs/guide_docx.py. Use the bundled Python environment with python-docx and Pillow. The workstation command is printed in the combined manual. Build-PlatformGuides.py --audit checks inventory and paths without authoring; --html-only refreshes HTML presentation while preserving its existing embedded source snapshot; --preserve-source rebuilds the teaching text and Word layout using that same embedded snapshot. Refresh-GuideWord.py refreshes Word layout from existing teaching snapshots. Render-PlatformGuides.ps1 and Review-PlatformGuides.py produce internal page-review artifacts on Windows with Word and pypdfium2.

Only documentation, diagrams and documentation tooling belong to this change. Company Dash and the sibling SalesApi project remain separate projects. Do not use these examples to overwrite unrelated edits or alter real business records while learning.
