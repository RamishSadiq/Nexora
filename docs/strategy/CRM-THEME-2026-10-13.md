# CRM theme alignment — 13 October 2026

The CRM now follows the website studio and neon member portal palette: charcoal `#09090b`, mint `#50f5d6` and violet `#9255ff`. The previous burgundy navigation, pale tables and dashboard cards were the main visual gaps.

The implementation uses a shared CRM stylesheet and palette variables for the workspace shell, module primitives, record listings and details, dashboard cards and sign-in page. Glow stays concentrated on actions and active navigation. Sticky table headings, selection states, status colours, keyboard focus, mobile navigation and reduced-motion support retain their existing interactions.

The follow-up adds a persistent ambient layer beneath all CRM pages: broad mint/violet light, a faint grid and an orbital halo. Three soft gradients drift slowly through CSS transforms; they ignore pointer events, stay out of the accessibility tree, remain fixed behind scrolling content and switch to a static composition for reduced-motion preferences. Mobile reduces their intensity, and print hides the decoration. Dashboard cards now carry brighter mint/violet borders and tinted lighting. Opaque record surfaces preserve text readability.

Theme rules stop at website and portal preview renderers. Website previews retain their configured palette; both classic and neon portal previews remain readable inside the dark CRM. Printing uses a light palette. The website and portal presentation editors continue to own their separate configuration.

Verification covers the production frontend build and TypeScript, scoped ESLint, desktop/mobile browser checks for login, dashboard report flips, contacts, filter menus, record detail and creation forms, navigation, membership, finance and content management. Additional browser checks cover custom website preview colours, classic/neon portal previews, account popovers and print styling. No browser errors were observed. Checks use existing local records and leave creation forms unsaved; preview checks issued no Content API writes.

Evidence is saved in `artifacts/crm-theme-review.json`, `artifacts/crm-theme-preview-review.json` and `artifacts/crm-neon-*.png`. Local browser checks use the running CRM at `http://localhost:3017` with shared API `http://localhost:5097`. Build output uses the isolated `.next-crm-theme-review` directory. Full business regression and production deployment are outside this presentation change.
